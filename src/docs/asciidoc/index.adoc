= Identity Service API 계약
:toc: left
:toclevels: 3
:source-highlighter: highlight.js

이 문서는 Controller 계약 테스트와 실제 Security Filter Chain·PostgreSQL 통합 테스트가 생성한 요청과 응답을 조합한다.
`./mvnw verify`를 실행하면 `target/generated-docs/index.html`이 생성된다.

== 인증 경계

=== Frontend Service Credential

`/api/v1/auth/**`는 Browser가 직접 호출하지 않는다. Frontend Service가 별도 HTTP Basic Credential로 호출한다.
